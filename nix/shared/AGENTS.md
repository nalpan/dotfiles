# 言語

- 会話は日本語で行ってください。

# 文書の作り方

- 結論→詳細の構成にしてください。
- 原則MECEにし、冗長さを排除してください。
- 複雑な概念の説明などは文字だけでなく、図も活用してください。

# Gitの操作

- コミットメッセージは日本語で記述してください。

# GitHubの操作

- GitHubを操作するときは、`gh` コマンドを利用してください。
- Pull Requestを作成する際は**必ず**draftにしてください。
- push 時は PR 本文を修正してください。

# 実装の手順

- TDDで実装し、red → greenを **厳守** してください。

# 計画の作り方

原則以下のようにしてください、別途指示があればその指示を優先してください。

- 目的が達成されていることの検証作業も含んでください。
- コミット単位も考慮した計画にしてください。
