# 言語

- 会話は日本語で行うこと。

# 文書の作り方

- 結論→詳細の構成にすること。
- 原則MECEにし、冗長さを排除すること。
- 複雑な概念の説明などは文字だけでなく、図も活用すること。

# 調査と結果報告のルール

- 調査は必ず1次ソースを探すこと。
- 結果報告では事実と考察を分けて報告し、報告の元となる資料やそのURLを提供すること。

# Gitの操作

- コミットメッセージは日本語で記述すること。

# GitHubの操作

- GitHubを操作するときは、`gh` コマンドを利用すること。
- Pull Requestを作成する際は**必ず**draftにすること。
- push 時は PR 本文を修正すること。

# 実装について

- TDDで実装し、red → greenを **厳守** すること。
- 変数や関数などのシグネチャでドメイン知識を表現すること。
- コードへのコメント記述は簡潔な理由に留めること、実装や処理の詳細は書かない。

# 計画の作り方

原則以下のようにしてください、別途指示があればその指示を優先すること。

- 目的が達成されていることの検証作業も含むこと。
- コミット単位も考慮した計画にすること。
